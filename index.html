Trust, privacy & governance

Security center.

Security controls designed around least privilege, privacy and traceable actions.

Platform controls

⛨
Role-based access control

Separate applicant, recruiter, HR, representative, auditor and super-admin permissions.

⌑
Row-level security

Applicants can access only their own records. Privileged access is narrowly scoped.

✦
Multi-factor authentication

Require stronger authentication for administrators and authorized signatories.

▣
Private document storage

Use private buckets, expiring links, file validation and access logging.

◷
Audit and retention

Record critical changes and enforce documented retention and deletion schedules.

Biometric privacy controls

Sensitive biometric data requires a separate, explicit workflow.
